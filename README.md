# React Task Manager

A simple and efficient task management application built with React. This app allows users to add tasks, view them, and filter tasks by month.

## Features

- **Dynamic Header**: The header switches between two views (`Head` and `Sechead`) for a better user experience.
- **Task Management**: Add tasks with details such as title, day, month, and duration.
- **Task Display**: Tasks are displayed in a structured layout, showing the task details.
- **No Task View**: A message is shown when there are no tasks.
- **Filter Tasks by Month**: Users can filter tasks by the selected month (currently set to "All").

## Technologies Used

- **React**: A JavaScript library for building user interfaces.
- **Tailwind CSS**: A utility-first CSS framework for styling the application.
- **JavaScript (ES6+)**: Used for application logic, state management, and component interactions.
